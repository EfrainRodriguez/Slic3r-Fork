# Parameters Reference (INI + CLI)

This file documents the parameter set currently used in this project, what each parameter means,
and the usual CLI mapping.

## Conventions

- INI key: `snake_case` (example: `layer_height`)
- CLI flag: `--kebab-case` (example: `--layer-height`)
- Boolean in INI: usually `0` (off) / `1` (on)
- Percent values: `50%`, `75%`, etc.

## How to apply parameters

- Profile file: `--load profile.ini`
- CLI override: `--load profile.ini --layer-height 0.2 --fill-density 20% ...`
- Multiple profiles: `--load base.ini --load material.ini --load quality.ini ...`

Precedence: defaults < `--load` profiles < direct CLI flags.

If the same key appears multiple times, the later source wins.

## Common value formats

- Boolean values: usually `0`/`1` in INI.
- Percent values: `20%`, `50%`, `75%`.
- Coordinate vectors: `0x0`, `200x200`.
- Polygon/list values: `0x0,200x0,200x200,0x200`.
- Multi-value numeric arrays: comma-separated (common in multi-extruder settings).
- G-code text blocks: escaped newlines inside one value, for example `M104 S0\nM84\n`.

## Discover options from the current engine build

Use engine output as source of truth for your exact binary:

```bat
run-slicer.bat --help
run-slicer.bat --save defaults.ini
```

- `--help`: CLI-exposed flags and descriptions.
- `--save`: full defaults profile for audit/diff.

## Parameter dictionary

Each item shows: `ini_key` -> meaning (CLI: `--...`).

## Machine, geometry, and global behavior

- `avoid_crossing_perimeters` -> avoid crossing perimeters during travel to reduce scars (CLI: `--avoid-crossing-perimeters`).
- `bed_shape` -> printable bed polygon points (CLI: `--bed-shape`).
- `has_heatbed` -> indicates heated bed support in printer profile.
- `label_printed_objects` -> include object labels/comments in output when supported.
- `output_filename_format` -> template for autogenerated output names (CLI: `--output-filename-format`).
- `resolution` -> geometric simplification tolerance (0 = full detail) (CLI: `--resolution`).
- `threads` -> slicing thread count (CLI: `--threads`).
- `vibration_limit` -> frequency-based move limiting for ringing control (CLI: `--vibration-limit`).
- `z_offset` -> adds global Z offset to output coordinates (CLI: `--z-offset`).
- `z_steps_per_mm` -> optional Z quantization hint for firmware rounding (CLI: `--z-steps-per-mm`).

## Temperatures and thermal control

- `bed_temperature` -> bed temp after first layer (C) (CLI: `--bed-temperature`).
- `first_layer_bed_temperature` -> first layer bed temp (C) (CLI: `--first-layer-bed-temperature`).
- `temperature` -> nozzle temp after first layer (C) (CLI: `--temperature`).
- `first_layer_temperature` -> first layer nozzle temp (C) (CLI: `--first-layer-temperature`).
- `standby_temperature_delta` -> inactive tool temp delta in multi-extruder use (CLI: `--standby-temperature-delta`).
- `use_set_and_wait_bed` -> use wait-style bed temp commands when supported.
- `use_set_and_wait_extruder` -> use wait-style extruder temp commands when supported.

## Cooling and fan

- `cooling` -> enable cooling logic (CLI: `--cooling`).
- `fan_always_on` -> keep fan on at minimum speed (CLI: `--fan-always-on`).
- `fan_below_layer_time` -> fan increases if layer time is below threshold (CLI: `--fan-below-layer-time`).
- `disable_fan_first_layers` -> disable fan for first N layers (CLI: `--disable-fan-first-layers`).
- `min_fan_speed` -> minimum fan percent (CLI: `--min-fan-speed`).
- `max_fan_speed` -> maximum fan percent (CLI: `--max-fan-speed`).
- `bridge_fan_speed` -> fan percent during bridges (CLI: `--bridge-fan-speed`).
- `fan_percentage` -> fixed/legacy fan percent override behavior, profile dependent.
- `slowdown_below_layer_time` -> reduce print speed when layers are too fast (CLI: `--slowdown-below-layer-time`).
- `min_print_speed` -> lower bound for slowdown logic (CLI: `--min-print-speed`).

## Filament and material profile

- `filament_colour` -> metadata color tag for filament.
- `filament_cost` -> metadata cost per unit for estimates.
- `filament_density` -> material density used for mass estimates.
- `filament_diameter` -> filament diameter mm (CLI: `--filament-diameter`).
- `filament_max_volumetric_speed` -> volumetric cap for extrusion planning.
- `filament_notes` -> free-text notes for filament preset.
- `extrusion_multiplier` -> global flow multiplier (CLI: `--extrusion-multiplier`).
- `max_volumetric_speed` -> print-level volumetric limit.

## G-code templates and scripts

- `start_gcode` -> custom start sequence text (CLI: `--start-gcode` when file-based loading is used).
- `end_gcode` -> custom end sequence text (CLI: `--end-gcode` when file-based loading is used).
- `before_layer_gcode` -> code inserted before layer change (CLI: `--before-layer-gcode`).
- `layer_gcode` -> code inserted at layer change (CLI: `--layer-gcode`).
- `between_objects_gcode` -> code inserted between sequential objects.
- `toolchange_gcode` -> code inserted on tool switch (CLI: `--toolchange-gcode`).
- `start_filament_gcode` -> filament preset start snippet.
- `end_filament_gcode` -> filament preset end snippet.
- `post_process` -> external post-processing script(s) (CLI: `--post-process`).
- `notes` -> notes emitted as comments in output where applicable (CLI: `--notes`).
- `printer_notes` -> printer profile notes metadata.

## Motion mode and firmware dialect

- `extrusion_axis` -> extrusion axis letter, usually `E`.
- `gcode_arcs` -> emit G2/G3 arcs when possible (CLI: `--gcode-arcs`).
- `gcode_comments` -> include verbose comments in G-code (CLI: `--gcode-comments`).
- `gcode_flavor` -> target firmware dialect (CLI: `--gcode-flavor`).
- `pressure_advance` -> experimental pressure compensation constant (CLI: `--pressure-advance`).
- `use_firmware_retraction` -> use G10/G11 firmware retraction (CLI: `--use-firmware-retraction`).
- `use_relative_e_distances` -> relative extrusion distances (CLI: `--use-relative-e-distances`).
- `use_volumetric_e` -> volumetric E mode (CLI: `--use-volumetric-e`).

## Layering and quality

- `min_layer_height` -> minimum allowed adaptive/variable layer height.
- `max_layer_height` -> maximum allowed adaptive/variable layer height.
- `adaptive_slicing` -> enables adaptive layer sizing.

- `overhangs` -> overhang handling switch used by profile logic.
- `interface_shells` -> keep separate shells at interfaces when enabled.

## Notes

- Some keys are profile metadata or engine-internal knobs and may not have a dedicated CLI flag in
  all builds.
- Use `run-slicer.bat --help` as the definitive list of CLI-exposed options for this exact engine.
- Use `run-slicer.bat --save defaults.ini` to inspect effective default values for all keys.

## Practical override examples

### Force support off for one job

```bat
run-slicer.bat --load production.ini --support-material 0 --output out.gcode model.stl
```

### Keep profile but reduce infill and perimeters

```bat
run-slicer.bat --load production.ini --fill-density 20% --perimeters 2 --output out.gcode model.stl
```

### Export JSON with per-job overrides

```bat
run-slicer.bat --export-json --load production.ini --layer-height 0.2 --output out.json model.stl
```

The resulting JSON `print_config` reflects final resolved values used for that run.
